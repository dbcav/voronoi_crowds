How the crowd game works

Here we'll go through the second sheet in a bit more detail: what a mean field game is, which part of the game each slider changes, and how the page solves it (all in your browser).

What a mean field game is

Imagine a crowd of people trying to leave a room. Each person wants to reach the exit without walking too fast and without getting stuck in a crush near the door. The best route for any one person depends on where everyone else goes, and everyone else is making the same calculation. A mean field game describes the outcome when the crowd is large enough that no single person changes the picture very much. In that case each agent only needs to react to the crowd's density \(m(t, x)\) (roughly, how many people are near \(x\) at time \(t\)), rather than to each of its individual neighbours.

An "equilibrium" is a density and a plan that are consistent with each other: when everybody follows the plan, the crowd moves exactly the way \(m\) says it will, and given \(m\), nobody can lower their own cost by switching to a different plan. This consistency is what makes these agents look ahead. For example, if the near door is going to be jammed in half a second, some of the agents will already be heading for the far one.

The game on this page

Here the agents live in a domain \(\Omega\) (the room, including its walls). An agent at position \(x \in \Omega\) picks a velocity \(\alpha\) and moves with a little bit of randomness:

$$\mathrm{d}X_t = \alpha_t\,\mathrm{d}t + \sqrt{2\nu}\,\mathrm{d}W_t.$$

Each agent pays for effort, for crowding, and for whatever distance is left to go when time runs out:

$$J(\alpha) = \mathbb{E}\left[\int_0^T \Big(\tfrac12|\alpha_t|^2 + \kappa\, m(t, X_t)\Big)\,\mathrm{d}t \;+\; \gamma\, D(X_T)\right],$$

where \(\gamma\) is the urgency and \(D\) is the walking distance (around the walls) to the green target zone, so \(D = 0\) inside the zone. If we write \(u(t, x)\) for the best possible cost still to pay starting from \((t, x)\), then the equilibrium is described by the pair of equations

$$\begin{aligned} -\partial_t u - \nu\,\Delta u + \tfrac12 |\nabla u|^2 &= \kappa\, m, & u(T, \cdot) &= \gamma\, D,\\ \partial_t m - \nu\,\Delta m - \nabla\!\cdot\!\big(m\, \nabla u\big) &= 0, & m(0, \cdot) &= m_0. \end{aligned}$$

The first equation (the Hamilton–Jacobi–Bellman equation) runs backward in time from the deadline and gives everyone's best plan, which is to move with velocity \(\alpha^\ast = -\nabla u\). The second equation (the Fokker–Planck equation) runs forward in time from the starting crowd and moves the density along that plan. Each equation needs the other one's answer, and that coupling is what makes this a game rather than two separate problems. Since the crowding cost \(\kappa m\) increases with \(m\), the game has exactly one equilibrium.

The "crowd-blind" plan is the same game with \(\kappa = 0\). These agents plan as if the room were empty, but the results table still bills them for the crowding they actually cause.

What each parameter changes

Here's what each control on the second sheet does to the game (or, in a few cases, only to how the game is solved).

Parameter Symbol What it changes
Domain \(\Omega\) Where agents are allowed to be, which is the room shape picked with the "Room" buttons. Walls are removed from the mesh so nobody can cross them, and the distance \(D\) is measured around them.
Dashed circle \(m_0\) The starting crowd, a smooth bump filling the circle with total mass 1. You can drag it to move it, and use the square on its rim to resize it.
Green circle \(D\) The target zone. The terminal cost is zero inside it and grows with walking distance outside of it.
Dislike of crowds \(\kappa\) The price per unit of density, per unit of time. Higher values make the equilibrium spread out, split between doors, and stagger when agents leave.
Urgency \(\gamma\) The price per unit of distance still to go at the deadline. This also sets the top walking speed, since a planner far from the target moves at a speed close to \(\gamma\).
Randomness \(\nu\) The strength of the random jostling in each agent's motion. In the equations this is the diffusion term \(\nu\Delta\).
Time allowed \(T\) The deadline. With more time, agents can afford to wait for a jam to clear.
Mesh, Cells How space is cut into cells (relaxed with Lloyd's algorithm, Poisson disk, or uniform random seeds) and how many cells there are. This changes the numerical solution but not the game itself. Rougher meshes and fewer cells give more numerical smearing.
Rounds of play \(K\) How many rounds of fictitious play are used to find the equilibrium (see below). More rounds shrink the gap shown in the step 1 chart.
Agents \(N\) How many agents are drawn from \(m_0\) in step 2. This doesn't change the game, only how well \(N\) agents reproduce it.
Voronoi pressure Turns on the force from the first sheet, for the reacting crowd only. Without it, reacting agents ignore each other entirely.
Contact repulsion A short-range push between any two agents, applied to every crowd. Planning agents aren't expecting it, so it pulls them off of their plan.
Planners copy the scheme’s spread Whether planning agents add the random spread of the numerical solution (explained below), or just the \(\nu\) randomness.
Crowd-aware / crowd-blind plan \(\kappa\) or \(0\) Which equilibrium the left-hand panel and its agents show.

How it's solved

Space and time

We cut the domain into Voronoi cells \(V_i\) (see the "What's a Voronoi cell?" box on the main page). Two neighbouring cells \(i\) and \(j\) share an edge of length \(S_{ij}\), and their seeds are a distance \(d_{ij}\) apart. Time is split into 64 equal steps from \(0\) to \(T\). The distance \(D\) is computed on the graph of cells using Dijkstra's algorithm, starting from the cells inside the target zone.

The backward equation

On the mesh, an agent in cell \(i\) chooses how quickly to leave for each of its neighbours. Optimizing over that choice gives the discrete version of \(\tfrac12|\nabla u|^2\):

$$H_i(u) = \frac{1}{2|V_i|}\sum_j \frac{S_{ij}}{d_{ij}}\,\big((u_i - u_j)^+\big)^2.$$

This means an agent only ever moves toward neighbours where the cost to go is lower, and it does so at speed \((u_i - u_j)^+/d_{ij}\). Each backward time step is implicit, meaning it solves the full nonlinear equation for \(u\) at that step. We do this cell by cell, with a few Newton iterations per cell, and repeat the sweeps until nothing changes. Because the step is implicit, it stays stable for any step size.

The forward equation

Each backward step amounts to one matrix \(A^n\) acting on the values in every cell (so \(A^n u^n\) equals some known terms). The forward step for the density then uses exactly the transpose of that matrix:

$$(A^n)^{\mathsf T}\, m^{n+1} = \frac{|V|\, m^n}{\Delta t}.$$

This choice has three nice consequences. First, the total mass of the crowd never changes. Second, the density never goes negative. Third, the cost to go at the start, averaged over the starting crowd, equals the total cost the crowd actually pays along the way (the page checks this to about nine digits). This is the same transpose trick that's behind adjoint methods and backpropagation.

Finding the equilibrium: fictitious play

We start with a guess \(\bar m^{(0)}\) for the crowd (everyone standing still), and then repeat the following round \(K\) times. First, we solve the backward equation against the current guess, which gives everyone's best plan. Then we push \(m_0\) forward along that plan, which gives the crowd \(\hat m^{(k)}\) that would actually result. Finally, we fold this into the guess as a running average:

$$\bar m^{(k+1)} = \bar m^{(k)} + \frac{1}{k+1}\big(\hat m^{(k)} - \bar m^{(k)}\big).$$

At an equilibrium the guess and the resulting crowd agree, and the chart under step 1 plots how far apart they still are. The crowd-blind game only needs one round, since its plan doesn't depend on the crowd at all.

From the density back to agents

In step 2 we draw \(N\) starting spots in proportion to \(m_0\), and all three crowds start from these same spots. A planning agent reads its velocity off of the solution in its current cell, blended smoothly with the neighbouring cells. The numerical scheme also spreads the crowd out a little more than \(\nu\) alone would (because of the way it moves density between cells), so planners copy that extra spread too. That way, \(N\) planning agents reproduce the equilibrium we actually computed, rather than a sharper version of it.

Reacting agents use the same velocity rule, but with the cost to go replaced by the end-of-game cost \(\gamma D\) alone. You can think of this as a plan with zero foresight, with Voronoi pressure added on top if it's switched on. Every agent is billed with the game's cost \(J\), using the crowd's own density on the mesh, and those bills are what fill in the results table.

Things to keep in mind

This is a small model, chosen so that it runs in a browser in a few seconds. The mesh is coarse (a few hundred to about 1,600 cells), and the equilibrium is only as sharp as the mesh allows. Fictitious play also converges slowly, so 30 rounds gets close but not all the way there. The crowding cost only depends on the density right where an agent is standing, whereas real people also react to what they see ahead of them. Finally, on random meshes the discrete game can behave slightly differently in different directions, which is one reason the relaxed mesh is the default.
